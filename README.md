# 金銭出納帳（エクセル 無料）｜簡易出納帳 — iGenTrade / 合同会社威源国際貿易

「**金銭出納帳 エクセル 無料**」で探している方向けの、ブラウザ版 **金銭出納帳（簡易出納帳）** です。  
Excel テンプレートの代わりに、登録なし・無料で収支管理できます。CSV は Excel 向け（UTF-8 BOM）です。

## エクセル無料テンプレの代わりにできること

- 取引の追加・編集・削除（日付 / 収入・支出 / カテゴリ / 金額 / 消費税 / メモ / 支払方法）
- 消費税 10%・8%（軽減）・0%（非課税等）、税込/税抜入力
- 収入・支出カテゴリ（編集可）
- 期間・区分・カテゴリ・メモでの絞り込み
- 残高・期間合計・月次集計
- **CSV 出力（Excel で開ける）** と CSV 取込
- 印刷 / PDF（帳票フッターの提供元表示は通常オフ）
- データはブラウザ内のみ（外部送信なし）

## 使い方

1. デモページを開く: https://igentrade.github.io/igentrade-suitoubo/
2. 左のフォームで取引を入力
3. 必要なら CSV を Excel に取り込んで二次編集
4. 「月次レポート印刷 / PDF」で保存
